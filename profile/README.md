# CMU Minecraft

Carnegie Mellon's Minecraft Multiplayer Server: a virtual campus, the
Homecoming Build Competition, and survival with other CMU players. Bring the
Java edition and an @andrew.cmu.edu or @alumni.cmu.edu account.

- **Play:** [get started](https://cmumc.github.io/get-started.html) at `mc.andrew.cmu.edu`
- **Watch:** [CMUMC on YouTube](https://www.youtube.com/channel/UCsDxCj69bfDk16bq2C8YhCQ)
- **Build:** [mc-server](https://github.com/CMUMC/mc-server), the server's setup, and [cmumc.github.io](https://github.com/CMUMC/cmumc.github.io), the site
